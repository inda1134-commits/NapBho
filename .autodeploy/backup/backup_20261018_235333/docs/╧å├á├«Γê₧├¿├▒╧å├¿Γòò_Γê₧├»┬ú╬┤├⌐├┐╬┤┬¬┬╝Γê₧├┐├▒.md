# 기본 테스트 시나리오

1. "취득세가 잘못 나왔어요" → `OTHER`, 국세청 권리구제 절차 추천 금지.
2. "소득세가 왜 나왔는지 모르겠고 고지서를 받았어요" → 국세청 가능성, 고지일·세목·사전 설명 확인.
3. "이미 신고했는데 자료를 제출하라고 해요" → 세목과 문서 종류 확인, 담당자 문의. 고지 전 경정청구/불복 자동 추천 금지.
4. "세무조사가 끝났어요" → 과세예고통지/고지 여부를 먼저 확인.
5. "불복기간이 지났어요" → 통지일과 처분 종류 확인, 기한 경과를 자동 확정하지 않음.
6. "세금이 뭔지 알려주세요" → 국세상담센터 등 단순 상담 경로.
7. "조사 담당자가 범위 밖 자료를 계속 요구해요" → 세무조사 관련 권리보호 절차 검토.
8. PDF 업로드 후 "권리보호요청" 선택 → 문서명·페이지를 표시한 검색 결과.
9. 관련 PDF에 근거가 없으면 → 근거 없음 경고, 조문/기한을 만들어내지 않음.
10. 사용자가 처음부터 다시 시작을 누르면 세션이 초기화됨.
