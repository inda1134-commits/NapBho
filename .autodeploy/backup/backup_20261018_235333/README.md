# 납세자 권리보호 안내 AI (프로토타입)

## 핵심 흐름
1. 사용자가 일상적인 말로 불만사항을 입력합니다.
2. 앱이 다음 5개 항목을 자동 분류합니다.
   - **소관기관**: 불만사항을 유발한 행정기관
   - **세목**: 국세청 소관 세목 사전, 약칭 및 오타 유사도 기반 후보
   - **과세단계**: 사업자등록, 신고, 세무조사, 과세(과세예고·고지 포함), 불복, 체납, 민원 등
   - **처분행위**: 안내, 자료제출 요구, 통지, 고지, 독촉, 압류 등
   - **요구목적**: 사용자가 궁극적으로 원하는 결과
3. 분류 항목을 사용자가 직접 선택하지 않고, 필요한 사실관계만 대화형 질문으로 하나씩 확인합니다.
4. 국세청 소관이 아니면 소관기관과 국민신문고를 안내하고 국세청 권리구제 검토를 종료합니다.
5. 확인된 사실관계에 따라 해결 경로를 검토하며, 가능한 해결 방법이 두 가지 이상이면 사용자가 진행할 방법을 선택합니다.
6. 선택된 해결 경로와 확정된 사실관계를 LLM에 전달해 안내 유형과 실행 안내를 작성합니다.

## 실행
```bash
python -m venv .venv
.venv\\Scripts\\activate
pip install -r requirements.txt
copy .env.example .env
streamlit run app.py
```

API 키는 `.env` 또는 사이드바에서 설정할 수 있습니다. API 키 없이도 규칙 기반 분류를 실행할 수 있습니다.

## 세목 유사도에 관한 주의
세목 매칭은 흔한 약칭·오타를 보정하기 위한 후보 생성 기능입니다. 문자열 유사도 점수는 법적 판단의 확률이 아니며, 사용자가 결과를 확인·수정하도록 설계했습니다. 지방세·관세 등 타 기관 소관 세목은 국세청 세목으로 억지 매핑하지 않습니다.

## 프로토타입 한계
- 규칙 및 세목 사전은 초기 목록이므로 실제 운영 전 현행 법령·업무규정과 대조해 보완해야 합니다.
- 법정기한을 자동 확정하지 않습니다. 문서 종류·송달일·절차별 기한을 담당기관에서 확인해야 합니다.
- LLM 출력과 키워드 분류는 참고자료이며, 공식적인 세무·법률 판단을 대체하지 않습니다.
- PDF 검색은 업로드한 자료에 한정됩니다. 문서의 최신성·적용 가능성을 별도로 확인해야 합니다.

## 대화형 분류 방식

사용자는 불만사항을 자연어로 입력합니다. 시스템은 분류 항목을 직접 선택하도록 요구하지 않고, 해결 경로 판단에 필요한 미확인 사실만 대화 입력창을 통해 순차적으로 확인합니다. 선택지와 예시는 참고용으로 표시되며 사용자는 자연어로 답변할 수 있습니다.


## 최종 안내 유형

- **단순 안내**: 간단한 설명과 국세상담센터(국번 없이 126) 연결
- **신고·서류 제출**: 설명, 준비·제출 서류와 홈택스 연결
- **구제절차**: 신청 대상 및 절차, 제출 서류, 제출기관과 공식 사이트 안내
- **권리보호**: 권리보호 요청 대상, 절차, 첨부서류 및 국세청 공식 사이트 안내

LLM은 대화에서 확정된 사실과 사용자가 선택한 해결 방법을 바탕으로 안내문을 작성합니다. 공식 서식·기한·적용 요건은 담당 기관에서 최종 확인해야 합니다.


## 상담 화면과 참고자료 벡터 DB

- 상담 화면은 넓은 왼쪽 영역(질문 입력·진행 질문·최종 안내문)과 좁은 오른쪽 영역(카카오톡 형식의 질문·답변 기록)으로 나뉩니다.
- 사이드바의 **참고자료 벡터 DB**에서 과세단계별 법령·업무 안내 PDF를 올리고 **벡터 DB 생성 / 자료 추가**를 누르면 Chroma 영구 컬렉션에 저장됩니다.
- 임베딩 생성에는 `OPENAI_API_KEY`가 필요하며 `text-embedding-3-small`을 사용합니다. `.env`의 `CHROMA_PATH`와 `CHROMA_COLLECTION` 또는 사이드바 입력값으로 저장 위치와 컬렉션을 정할 수 있습니다.
- 상담 시 저장된 벡터 DB에서 관련 근거를 검색해 LLM의 해결 방법 선정과 최종 안내문 작성 프롬프트에 전달합니다. 현재 화면에 업로드한 PDF도 키워드 검색으로 함께 보조합니다. 검색된 근거는 최종 안내문 아래 **참고자료 검색 근거(RAG)**에서 확인할 수 있습니다.
- PDF가 이미지 스캔본이면 텍스트 추출이 되지 않을 수 있으므로 OCR 처리된 PDF를 사용하세요.


## 이번 보완사항

- 기한 관련 질문은 날짜를 직접 입력받지 않고 `30일 내`, `60일 내`, `90일 내`, `잘 모르겠음` 범주로 확인합니다. 이 선택은 법정기한을 확정하지 않으며, 세무조사·과세전적부심사·불복·권리보호 등 적절한 절차를 우선 검토하도록 돕습니다.
- 참고자료 검색은 설정된 Chroma 벡터 DB 컬렉션만 사용하며, 현재 업로드 파일의 임시 키워드 검색으로 폴백하지 않습니다. PDF 청크 메타데이터에 `source_filename`(출처 파일명), `filename`, `page`를 저장하여 검색 근거의 출처를 추적할 수 있습니다.
- 사업자등록 해결방안 목록에 신규 신청, 정정·변경, 휴업, 폐업 안내 항목을 추가했습니다.


## 주요 국세 불복절차 상세 안내

선택된 해결방법이 과세전적부심사청구, 이의신청, 심사청구 또는 심판청구인 경우 안내문에 신청요건, 신청절차, 처리절차, 법률 효과 및 기한 관련 주의를 구분해 표시합니다. 해당 절차명과 세부 질문을 사용해 지정된 Chroma 벡터 DB에서 참고자료를 다시 검색하며, 검색 결과의 출처 파일명과 페이지를 안내에 표시합니다. 직접 근거가 검색되지 않으면 구체적인 법적 요건이나 효과를 확정하지 않고 공식 자료 확인이 필요하다고 표시합니다.

`knowledge/불복절차_상세안내_참고자료.md`는 답변 구조 및 점검용 템플릿입니다. 운영 시 현행 국세기본법, 국세청 납세자 권리구제 안내, 조세심판원 공식 자료 등을 PDF로 확보하여 사이드바에서 벡터 DB에 등록해야 해당 자료가 RAG 답변의 근거로 사용됩니다. 템플릿 자체가 벡터 DB에 자동 등록되는 것은 아닙니다.
