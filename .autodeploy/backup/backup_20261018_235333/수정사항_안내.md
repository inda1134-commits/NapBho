# 납세자 권리보호 상담 프로젝트 수정사항

## 반영 내용
1. 초기 불만 접수에서 '원하는 해결'을 질문하지 않도록 변경했습니다. 해결 방법을 확정한 뒤 선택한 방법과 누적 답변을 `desired_outcome` 및 `confirmed_facts`에 반영해 최종 안내를 작성합니다.
2. 화면의 상담 이력은 필요한 질문과 사용자 답변 중심으로 표시하고, 분류·내부 분석 결과는 일반 상담 화면에서 숨겼습니다.
3. 사업자등록·신고·세무조사·과세(과세예고·고지 통합)·불복·체납·권리구제·민원 단계별 해결 방법 후보를 적용했습니다. 문제 키워드가 명확하면 해당 방법을 우선 제안합니다.
4. 권리보호 유형의 최종 안내에는 제도 설명, 신청 대상 확인, 진행 절차, 준비자료, 납세자보호담당관, 국선대리인 지원 대상 확인 및 불복기한 주의사항을 포함합니다.
5. 입력은 화면 상단의 상담 입력 폼으로 바꾸고, '새 상담 시작'은 화면 맨 아래에 배치했습니다.
6. 상담원 콘셉트의 색상·카드·단계 배지·안내문 스타일을 적용했습니다.
7. 사이드바에서 과세단계별 참고 PDF를 업로드할 수 있도록 했습니다.

## 실행
기존 환경과 동일하게 프로젝트 폴더에서 `pip install -r requirements.txt` 후 `streamlit run app.py`로 실행합니다.

## 주의
제도별 신청 요건·기한·국선대리인 지원 범위는 사건과 현행 규정에 따라 달라질 수 있으므로, 최종 안내에 담당 기관의 확인이 필요하다는 주의사항을 유지했습니다.
